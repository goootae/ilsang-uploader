개인정보처리방침 / Privacy Policy

ilsang-uploader · 시행일 / Effective date: 2026-11-19

1. 무엇을 하는 도구인가요 / What this app does

채널 운영자 본인이 만든 영상을 본인의 유튜브 채널에 올리는 개인용 도구입니다. 운영자 외의 사람은 사용하지 않습니다.

This is a personal tool. The channel owner uses it only to upload their own videos to their own YouTube channels. Nobody else uses it.

2. 요청하는 권한과 쓰는 정보 / Permissions and data used

  • youtube.upload: 영상과 제목·설명·태그·공개 범위를 올립니다. / Uploads videos and their title, description, tags and privacy setting.
  • youtube.readonly: 로그인한 채널의 이름·ID와 올린 영상의 처리 상태를 확인합니다. / Reads the signed-in channel's name and ID and the processing status of uploaded videos.

그 밖의 개인정보(연락처, 시청 기록, 댓글 등)는 읽지 않습니다.

No other personal data (contacts, watch history, comments, etc.) is accessed.

3. 저장과 공유 / Storage and sharing

로그인 토큰은 운영자 본인의 컴퓨터에만 저장되며, 어떤 서버로도 보내지 않습니다. 정보를 제3자에게 팔거나 공유하지 않고, 광고·분석 도구나 쿠키를 쓰지 않습니다.

Sign-in tokens are stored only on the owner's own computer and are never sent to any other server. No data is sold or shared with third parties. No advertising, analytics or cookies are used.

4. 권한 철회 / Revoking access

언제든지 Google 계정 → 타사 앱 및 서비스에서 이 앱의 접근 권한을 삭제할 수 있습니다. 삭제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

Access can be revoked at any time at Google Account → Third-party apps & services. After revocation the stored token can no longer be used.

5. YouTube API 서비스 / YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 사용할 때는 YouTube 서비스 약관이 적용되며, Google의 정보 처리는 Google 개인정보처리방침을 따릅니다.

This app uses YouTube API Services. Use is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

6. 문의 / Contact

채널 일상이 판타지다의 정보 탭을 통해 문의할 수 있습니다. / Contact via the channel's About page.
